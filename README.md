# AI Resume Analyzer

An AI-powered Resume Analyzer web application built using Flask and Python.

## Features

- Upload Resume PDF
- Extract Resume Text
- ATS Score Calculation
- Skill Extraction
- Missing Skills Detection
- Job Recommendations
- AI Resume Suggestions

## Technologies Used

- Python
- Flask
- HTML
- CSS
- PyPDF2

## How to Run

1. Clone the repository
2. Create virtual environment
3. Install dependencies
4. Run app.py

```bash
pip install flask PyPDF2
python app.py
